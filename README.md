## 🌟 Features

- **Futuristic & Clean Design**: Glassmorphism aesthetic with neon glows, card elevation, and smooth gradients.
- **Real Profile Image**: Embedded high-resolution photo with glowing borders and floating tech badges.
- **Dark / Light Mode**: Seamless theme toggle with state stored persistently in `localStorage`.
- **Interactive Constellation Canvas**: Background particle system that reacts subtly to mouse hover.
- **Dynamic Typing Animation**: Rotating badges and career titles in the hero banner.
- **Fully Responsive**: Mobile-first architecture with smooth sliding drawer menu and sticky glass navbar.
- **Interactive Contact Features**: Click-to-call (`tel:`), click-to-email (`mailto:`), 1-click copy email button, and validated message form with toast feedback.
- **Project Showcase with Category Filters**: Filter projects between Web Development and C/C++ logic systems.
- **Interactive Certificate Modal**: Fullscreen modal viewer for certificates and credentials.
- **100% Standalone**: No node modules, build pipelines, or heavy frameworks needed. Just open in any browser!

## 🌐 How to Deploy for Free

### 1. GitHub Pages (Recommended)
1. Create a new GitHub repository named `portfolio` or `<your-username>.github.io`.
2. Push all files in this folder to the repository.
3. Go to **Repository Settings** ➔ **Pages** ➔ Set Branch to `main` / `root` ➔ Click **Save**.
4. Your website is live worldwide!

### 2. Vercel / Netlify
- Drag and drop the `arvind_protfolio` folder directly into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
